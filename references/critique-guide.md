# 디자인 평가 심화 가이드

> Phase 7의 상세 참고 자료. 채점 기준, 상황별 중점, 자주 나오는 문제 목록을 담았다.

---

## 채점 기준 상세

### 0. 개념·의도(Concept) · 가중치 최상위

먼저 「이 디자인에 idea가 있는가」를 묻고, 그다음에 잘 만들었는지를 본다. 0번 자리에 둔 이유는 이렇다. 실행은 증폭기다. 텅 빈 개념을 증폭하면 더 텅 비어 보일 뿐이다.

| 점수 | 기준 |
|------|------|
| 9-10 | 사용자의 내용에서 자라난 고유한 idea가 있고, 시각 모티프를 다른 것으로 바꿀 수 없다 |
| 7-8 | 의도가 분명하고 모티프가 내용과 관련 있지만, 비슷한 주제로 바꿔도 그럭저럭 쓸 수 있다 |
| 5-6 | 스타일만 있고 개념이 없다. 보기는 좋은데 아무 말도 하지 않는다 |
| 3-4 | 범용 템플릿에 껍데기만 씌웠고 개념 층위는 0이다 |
| 1-2 | 스타일 선택조차 틀렸고 장식만 쌓아 올렸다 |

**핵심 질문 목록**:
- 이 디자인은 무엇을 말했는가? 그 idea를 한 문장으로 말할 수 있는가? 못 하면 없는 것이다
- 모든 글자와 logo를 가려도 주제를 알아볼 수 있는가? 못 알아보면 시각이 표현을 감당하지 않은 것이다(글자 자체가 모티프인 조판 디자인은 예외다. 그때는 이렇게 묻는다 — 이 글자 처리를 다른 주제에 옮겨도 성립하는가)
- 고객 이름이나 제품 이름을 바꿔도 성립하는가? **성립한다 = 템플릿이고, 이 차원은 바로 5점 이하다**
- form에 내용에서 나온 고유한 시각 모티프가 있는가?(SKILL.md의 form 도출과 호응한다. 형식은 내용에서 끌어내야 하고, 스타일 목록에서 뽑아 오는 게 아니다)

**단독 부결 규칙**: 개념이 5점 이하면 총평은 6.0(양호 등급의 하한)에서 막힌다. 뒤의 5개 차원은 전부 execution이고, execution이 아무리 정교해도 idea가 없는 디자인을 되돌려 놓지는 못한다 — 그건 템플릿을 더 반짝이게 닦은 것일 뿐이다.

### 1. 철학 일관성(Philosophy Alignment)

| 점수 | 기준 |
|------|------|
| 9-10 | 디자인이 선택한 철학의 핵심 정신을 완벽하게 구현했고, 모든 디테일에 철학적 근거가 있다 |
| 7-8 | 전체 방향이 맞고 핵심 특징도 살아 있지만 일부 디테일이 어긋난다 |
| 5-6 | 의도는 보이는데 실행할 때 다른 스타일 요소가 섞여 순수하지 않다 |
| 3-4 | 표면만 따라 했고 철학의 속을 이해하지 못했다 |
| 1-2 | 선택한 철학과 사실상 무관하다 |

**평가 포인트**:
- 그 디자이너나 기관의 상징적인 수법을 썼는가?
- 색채, 글꼴, 레이아웃이 그 철학 체계에 맞는가?
- 「스스로 모순되는」 요소가 있는가?(예: Kenya Hara를 골라 놓고 내용을 빈틈없이 채우기)

### 2. 시각 위계(Visual Hierarchy)

| 점수 | 기준 |
|------|------|
| 9-10 | 사용자의 시선이 설계자의 의도대로 자연스럽게 흐르고, 정보를 얻는 데 마찰이 없다 |
| 7-8 | 주종 관계가 분명하고, 위계가 모호한 곳이 1-2군데 있다 |
| 5-6 | 제목과 본문은 구분되지만 중간 위계가 뒤엉켜 있다 |
| 3-4 | 정보가 평평하게 깔려 있고 시각적 입구가 분명하지 않다 |
| 1-2 | 어수선해서 사용자가 어디를 먼저 볼지 모른다 |

**평가 포인트**:
- 제목과 본문의 자크기 대비가 충분한가?(최소 2.5배)
- 색·굵기·크기로 분명한 위계 3-4단을 세웠는가?
- 여백이 시선을 이끌고 있는가?
- 「눈 가늘게 뜨기 테스트」: 눈을 가늘게 뜨고 봐도 위계가 여전히 분명한가?

### 3. 디테일 실행(Craft Quality)

| 점수 | 기준 |
|------|------|
| 9-10 | 픽셀 단위로 정확하고, 정렬·간격·색에 흠이 하나도 없다 |
| 7-8 | 전체적으로 정교하고, 아주 작은 정렬·간격 문제가 1-2군데 있다 |
| 5-6 | 정렬은 기본적으로 됐지만 간격이 통일되지 않고 색 사용이 체계적이지 않다 |
| 3-4 | 정렬 오류가 눈에 띄고 간격이 뒤엉켰고 색이 너무 많다 |
| 1-2 | 거칠어서 초안처럼 보인다 |

**평가 포인트**:
- 통일된 간격 체계를 썼는가?(예: 8pt 그리드)
- 같은 종류 요소의 간격이 일치하는가?
- 색의 수가 통제되고 있는가?(보통 3-4가지를 넘기지 않는다)
- 글꼴 가족이 통일됐는가?(보통 2가지를 넘기지 않는다)
- 가장자리 정렬이 정확한가?

### 4. 기능성(Functionality)

| 점수 | 기준 |
|------|------|
| 9-10 | 모든 디자인 요소가 목표에 봉사하고 군더더기가 없다 |
| 7-8 | 기능 지향이 분명하고, 덜어낼 수 있는 장식이 조금 있다 |
| 5-6 | 기본적으로 쓸 만하지만 주의를 흩뜨리는 장식 요소가 뚜렷하다 |
| 3-4 | 형식이 기능을 넘어서서, 사용자가 정보를 찾으려 애써야 한다 |
| 1-2 | 장식에 완전히 잠겨서 정보를 전달하는 능력을 잃었다 |

**평가 포인트**:
- 어떤 요소든 하나 지우면 디자인이 나빠지는가?(나빠지지 않으면 지워야 한다)
- CTA와 핵심 정보가 가장 눈에 띄는 자리에 있는가?
- 「보기 좋아서 넣었다」는 요소가 있는가?
- 정보 밀도가 매체와 맞는가?(PPT는 너무 빽빽하면 안 되고, PDF는 더 빽빽해도 된다)

### 5. 창의성(Originality)

| 점수 | 기준 |
|------|------|
| 9-10 | 눈이 번쩍 뜨이고, 그 철학의 틀 안에서 고유한 표현을 찾아냈다 |
| 7-8 | 자기 생각이 있고, 단순한 템플릿 적용이 아니다 |
| 5-6 | 무난하고, 템플릿처럼 보인다 |
| 3-4 | cliché를 많이 썼다(예: 그라데이션 구체로 AI를 표현하기) |
| 1-2 | 완전히 템플릿이거나 소재를 이어 붙인 것이다 |

**평가 포인트**:
- 흔한 cliché를 피했는가?(아래 「자주 나오는 문제 목록」 참고)
- 디자인 철학을 따르면서도 자기 표현이 있는가?
- 「예상하지 못했는데 납득되는」 디자인 결정이 있는가?

## 상황별 평가 중점

산출물 종류에 따라 평가의 중점이 다르다(개념 차원은 표에 없다. 모든 상황에서 첫 관문이고, 중점을 저울질하는 대상이 아니다):

| 상황 | 가장 중요한 차원 | 그다음 | 완화 가능 |
|------|-----------|--------|--------|
| 위챗 공식계정 표지·삽화 | 창의성, 시각 위계 | 철학 일관성 | 기능성(단일 이미지는 인터랙션이 없다) |
| 인포그래픽 | 기능성, 시각 위계 | 디테일 실행 | 창의성(정확성 우선) |
| PPT/Keynote | 시각 위계, 기능성 | 디테일 실행 | 창의성(명료성 우선) |
| PDF/백서 | 디테일 실행, 기능성 | 시각 위계 | 창의성(전문성 우선) |
| 랜딩 페이지·공식 사이트 | 기능성, 시각 위계 | 창의성 | —(전 항목 요구) |
| App UI | 기능성, 디테일 실행 | 시각 위계 | 철학 일관성(사용성 우선) |
| 샤오홍슈 이미지 | 창의성, 시각 위계 | 철학 일관성 | 디테일 실행(분위기 우선) |

## 자주 나오는 디자인 문제 Top 10

### 1. AI 테크 cliché
**문제**: 그라데이션 구체, 디지털 비, 파란 회로 기판, 로봇 얼굴
**왜 문제인가**: 사용자는 이런 시각에 이미 지쳐 있어서 나와 남을 구분하지 못한다
**해결**: 직설적인 기호를 추상적인 은유로 바꾼다(예: 채팅 말풍선 아이콘 대신 「대화」의 은유를 쓴다)

### 2. 자크기 위계 부족
**문제**: 제목과 본문의 차이가 너무 작다(2.5배 미만)
**왜 문제인가**: 사용자가 핵심 정보를 빠르게 찾지 못한다
**해결**: 제목을 본문의 최소 3배로 한다(예: 본문 16px → 제목 48-64px)

### 3. 색이 너무 많다
**문제**: 5가지 이상을 쓰고 주종이 없다
**왜 문제인가**: 시각이 어수선해지고 브랜드 느낌이 약해진다
**해결**: 주색 1 + 보조색 1 + 강조색 1 + 그레이스케일로 제한한다

### 4. 간격이 통일되지 않았다
**문제**: 요소 간격이 제멋대로이고 체계가 없다
**왜 문제인가**: 전문적으로 보이지 않고 시각 리듬이 흐트러진다
**해결**: 8pt 그리드 체계를 세운다(간격은 8/16/24/32/48/64px만 쓴다)

### 5. 여백 부족
**문제**: 모든 공간이 내용으로 채워져 있다
**왜 문제인가**: 정보가 붐벼서 읽기에 지치고, 오히려 정보 전달 효율이 떨어진다
**해결**: 여백이 전체 면적의 최소 40%를 차지하게 한다(미니멀 스타일은 60% 이상)

### 6. 글꼴이 너무 많다
**문제**: 3가지 이상을 쓴다
**왜 문제인가**: 시각적 잡음이 되고 통일감을 깎아먹는다
**해결**: 글꼴은 최대 2가지(제목용 1 + 본문용 1). 자중과 크기로 변화를 만든다

### 7. 정렬이 일관되지 않았다
**문제**: 어떤 건 왼쪽, 어떤 건 가운데, 어떤 건 오른쪽 정렬이다
**왜 문제인가**: 시각적 질서가 깨진다
**해결**: 정렬 방식 하나를 정하고(왼쪽 정렬 권장) 전체를 통일한다

### 8. 장식이 내용을 넘어선다
**문제**: 배경 패턴·그라데이션·그림자가 주요 내용의 자리를 빼앗는다
**왜 문제인가**: 앞뒤가 뒤바뀐 것이다. 사용자는 정보를 보러 왔고 장식을 보러 온 게 아니다
**해결**: 「이 장식을 지우면 디자인이 나빠지는가?」 나빠지지 않으면 지운다

### 9. 사이버 네온 남용
**문제**: 진한 남색 바탕(#0D1117) + 네온 발광 효과
**왜 문제인가**: 기본적으로 미감상 금지 구역이고(이 skill의 취향 기준선), 이미 가장 큰 cliché 중 하나가 됐다 — 사용자는 자기 브랜드에 맞춰 override할 수 있다
**해결**: 더 알아볼 만한 배색을 고른다(20가지 스타일의 색채 체계를 참고한다)

### 10. 정보 밀도가 매체와 맞지 않는다
**문제**: PPT에 글자를 한 페이지 가득 넣기 / 표지 이미지에 요소 10개를 밀어 넣기
**왜 문제인가**: 매체마다 최적 정보 밀도가 다르다
**해결**:
- PPT: 한 페이지에 핵심 논점 1개
- 표지 이미지: 시각 초점 1개
- 인포그래픽: 층을 나눠서 보여준다
- PDF: 더 빽빽해도 되지만 분명한 내비게이션이 필요하다

## 평가 출력 템플릿

```
## 디자인 평가 보고

**총점**: X.X/10 [우수(8+)/양호(6-7.9)/개선 필요(4-5.9)/불합격(<4)]
(개념이 5점 이하면 총평은 6점에서 막힌다. 개념을 먼저 고치고 실행을 논한다)

**항목별 점수**:
- 개념·의도: X/10 [이 디자인의 idea는 무엇인가? 한 문장으로 말한다]
- 철학 일관성: X/10 [한 문장 설명]
- 시각 위계: X/10 [한 문장 설명]
- 디테일 실행: X/10 [한 문장 설명]
- 기능성: X/10 [한 문장 설명]
- 창의성: X/10 [한 문장 설명]

### 좋은 점(Keep)
- [잘한 부분을 구체적으로 짚고 디자인 언어로 서술한다]

### 문제(Fix)
[심각한 순서대로]

**1. [문제 이름]** — ⚠️치명 / ⚡중요 / 💡개선
- 현재: [현 상태 서술]
- 문제: [왜 문제인가]
- 해결: [구체적인 조작, 수치 포함]

### 빠른 수정 목록(Quick Wins)
5분밖에 없다면 이 3가지를 먼저 한다:
- [ ] [가장 영향이 큰 수정]
- [ ] [두 번째로 중요한 수정]
- [ ] [세 번째로 중요한 수정]
```
