# 웹툰 레시피

`webtoon-studio.mjs`가 읽는 spec 형식과 모드별 구성 규칙을 모았다. 이 문서의 구성표와 수치는 제작자 제안값이며 플랫폼 공식 규격이 아니다. 게시할 채널의 현행 규격은 올리기 전에 확인한다.

## 1. spec 필드

| 필드 | 설명 |
|---|---|
| `title` | 제목. 4컷·띠에서는 위쪽 제목 줄, `showTitle: false`로 끈다 |
| `kind` | `four-cut`(컷 정확히 4개) 또는 `episode`(10~30컷 권장) |
| `format` | 4컷 전용: `1x1`(1080×1080), `4x5`(1080×1350), `strip`(세로 띠, 너비 1080) |
| `width`, `gap`, `pageMaxHeight` | 스크롤 전용: 너비(에피소드 기본 800), 컷 사이 간격(기본 24), 페이지 최대 높이(기본 1280) |
| `style` | 화풍 한 줄. 모든 프롬프트에 들어간다 |
| `characters[]` | `name`, `anchor`(외형 고정 문장). 컷의 `characters`는 이 이름으로 가리킨다 |
| `palette` | `paper`(바탕), `ink`(선·글자), `accent`(강조), `main`(art 경로의 캐릭터 주색, 없으면 accent) |
| `artStyle` | art 경로의 질감: `clay`(그라데이션·번짐, 기본) 또는 `flat`(평면) |
| `font`, `fontFile`, `fontScale` | 글꼴 이름, 글꼴 파일 경로, 글자 크기 비율(4컷 0.075, 스크롤 0.045) |
| `footer` | 아래 안내 줄. 매장 주소·영업시간은 대표 확인 자료로 넣는다 |
| `panels[]` | 컷 목록 |

컷(`panels[]`)의 필드: `id`(필수, 중복 불가), `scene`, `shot`, `mood`, `characters[]`, `image`(래스터 컷 그림, spec 파일 기준 상대 경로), `art`(Claude가 그린 SVG 경로, image가 비었을 때만 렌더), `ratio`(스크롤 컷의 세로/가로 비율, 0.3~2.4), `caption`(위쪽 해설 박스), `bubbles[]`, `sfx[]`, `overlays[]`.

- `bubbles[]`: `type`(`say` 말, `think` 생각, `shout` 외침, `narration` 해설 상자, `review` 후기 인용), `text`, `x`·`y`·`w`(컷 크기에 대한 비율, 말풍선 왼쪽 위 기준), `tail`(`bl`·`br`·`tl`·`tr`·`none`). 위치를 생략하면 위에서 아래로 번갈아 놓인다. `review`는 `source`(출처)가 없으면 오류다.
- `sfx[]`: `text`, `x`·`y`(중심), `size`(컷 너비 대비 글자 크기, 기본 0.12), `rot`(기울기 도), `color`.
- `overlays[]`: `image`, `x`·`y`·`w`. 대표가 준 로고·간판·메뉴판 파일을 올린다. 생성 이미지로 로고를 그리지 않는다.

## 2. 4컷 문법

4컷은 한 컷에 한 가지 일만 일어나게 짠다. 기본 흐름은 도입(상황) → 전개(사건) → 전환(예상 밖 한 번) → 마무리(결론이나 행동 한 줄)다. 전환 컷이 약하면 3번 컷에 큰 컷 비중을 주고 4번 컷의 대사를 줄인다. 매장 홍보에서는 마지막 컷이 행동 안내(방문·주문·문의)가 된다.

대사 길이는 4컷 말풍선 28자(공백 제외) 이하를 권한다. 1080 정사각 캔버스는 휴대폰에서 폭 400px 안팎으로 줄어 보이므로 글자는 캔버스 기준 약 36px 이상이어야 읽힌다. `check`는 글자 수를, `compose`는 실제 글자 크기와 겹침·컷 이탈을 잡아 경고한다.

## 3. 매장 홍보형 시작 틀

세 틀 모두 `init --kind store-menu|store-event|store-review`로 시작 spec이 나온다. 인물은 사장님과 손님 두 명으로 시작한다.

| 틀 | 1컷 | 2컷 | 3컷 | 4컷 |
|---|---|---|---|---|
| 메뉴 소개 | 공감: 손님의 상황·고민 | 발견: 메뉴 등장 | 포인트: 재료·조리 방식 | 안내: 위치·시간·주문 방법 |
| 이벤트 안내 | 일상: 평소 매장 풍경 | 소식: 이벤트 공지 | 조건: 기간·조건·혜택 | 안내: 참여 방법·매장 정보 |
| 후기 소개 | 방문: 손님이 들어옴 | 선택: 메뉴 고르기 | 반응: 실제 후기 인용 | 마무리: 감사와 매장 정보 |

규칙은 다음과 같다.

- 가격·기간·수량·영업시간은 대표가 확인한 자료에서만 가져온다. `check`가 숫자가 들어간 대사를 목록으로 모아 주므로 그 목록을 자료와 하나씩 맞춘다.
- 후기는 실제 후기 원문과 출처가 있을 때만 쓴다. 후기·평점·수상 내역을 지어내지 않는다. 후기 원문은 한 글자도 고치지 않고 길면 앞뒤를 줄이되 줄였다고 표시한다.
- 매장 이름과 로고는 `overlays`, 주소와 영업시간은 `footer`에 넣는다. 그림 안에 간판 문구를 그리게 하지 않는다.
- 업종 특성상 과장·효능·비교 표현이 규제되는 업종(식품·건강·의료·금융 등)은 광고 문구가 관련 법규에 맞는지 대표와 확인한다. 이 스킬은 법률 판단을 하지 않는다.

## 4. 에피소드형(세로 스크롤)

한 회차는 보통 10~30컷이다. 컷 높이는 `ratio`로 정한다.

| 역할 | 권장 ratio | 쓰임 |
|---|---|---|
| 훅 컷 | 1.2~1.6 | 첫 화면. 인물·상황이 한눈에 들어오게 |
| 일반 대화 컷 | 0.8~1.1 | 대사 중심 |
| 작은 반응 컷 | 0.4~0.6 | 표정·리액션, 빠른 호흡 |
| 여백 컷 | 1.6~2.4 | 긴 침묵·장소 전환. 대사 없이 스크롤 호흡을 만든다 |
| 클라이맥스 컷 | 1.2~2.0 | 큰 그림 한 장 |

회차 구조는 훅(1~3컷) → 전개 → 전환 → 여운이나 다음 회차로 이어지는 마지막 컷이다. 큰 컷과 작은 컷을 번갈아 놓아 리듬을 만들고, 같은 크기의 대화 컷이 5개 넘게 이어지면 중간에 반응 컷이나 여백 컷을 끼운다. 말풍선은 한 컷에 3개 이하, 읽는 순서는 위에서 아래, 왼쪽에서 오른쪽이다.

페이지 분할은 `pageMaxHeight` 안에서 컷 경계에서만 자른다. 컷이 중간에 잘리지 않고, 이어 붙이면 `full.png`와 같아지도록 컷 아래 간격이 앞 페이지에 포함된다. 컷 하나가 한도보다 크면 혼자 한 페이지가 되고 경고가 나온다.

## 5. 프롬프트 작성 원칙

- 캐릭터 앵커 문장은 매 컷 맨 앞에 한 글자도 바꾸지 않고 붙인다. 컷마다 인물이 달라지는 원인 대부분이 이 문장의 변형이다.
- 그림 안에는 글자를 넣지 않는다. 생성 도구가 만든 글자는 깨지기 쉽고 고칠 수 없다. 글자는 합성 단계에서 올린다.
- 말풍선 자리는 비워 달라고 구체적으로 말한다. `prompts`가 말풍선 위치에서 비울 영역을 계산해 적는다.
- A안은 눈높이 정면에 가까운 읽기 쉬운 구도, B안은 같은 장면의 다른 연출(각도·거리·표정 강조)이다. 둘 중 나은 쪽을 고르거나, 한 컷 안에서 인물이 틀어지면 해당 컷만 다시 만든다.
- 한 컷에 인물이 둘 이상이면 두 사람의 앵커 문장을 모두 넣고 위치(왼쪽·오른쪽)를 정한다.

## 6. 출력 규격

| 형식 | 크기 | 쓰임 |
|---|---|---|
| 4컷 1x1 | 1080×1080 | 인스타그램 피드, 스레드 |
| 4컷 4x5 | 1080×1350 | 피드에서 더 크게 보이는 세로형 |
| 띠(strip) | 너비 1080, 높이 가변 | 블로그·상세 페이지에 붙이는 세로 이미지 |
| 에피소드 | 너비 800 기본, 페이지 최대 1280 | 세로 스크롤 연재형. 플랫폼 요구 규격이 있으면 `width`, `pageMaxHeight`로 맞춘다 |

`--scale 2`를 주면 같은 레이아웃을 2배 해상도로 낸다(1080 → 2160). 파일은 PNG다.

## 7. 납품 전 점검표

- [ ] `check`의 오류 0, 경고를 모두 읽고 처리했다
- [ ] 자리표시 컷이 0개다(`manifest.json`의 `placeholders`가 비어 있다)
- [ ] 같은 인물이 컷마다 같은 얼굴·머리·옷으로 보인다
- [ ] 그림 안에 생성된 글자·로고·간판 문구가 없다
- [ ] 말풍선이 컷 밖으로 나가거나 서로 겹치지 않는다
- [ ] 휴대폰 폭으로 줄였을 때 대사가 읽힌다
- [ ] 가격·기간·수치·후기가 대표 확인 자료와 일치한다. 후기에는 출처가 있다
- [ ] 로고·간판·사진은 대표가 준 실제 파일이다
- [ ] 실존 인물이나 기존 만화 캐릭터를 닮은 인물이 없다
- [ ] 글꼴과 그림 생성 도구의 상업 이용 조건을 확인했다

## 8. 막혔을 때

- `compose`가 「컷 이미지가 없는 컷」으로 멈춤: 그림을 연결하거나 레이아웃 리허설용으로 `--allow-placeholder`를 붙인다.
- 「그림 비율 ↔ 컷 비율 가장자리가 잘립니다」: 그림을 컷 비율에 맞춰 다시 만들거나 `ratio`를 그림 비율에 맞춘다. 그림은 컷을 채우도록 중앙 기준으로 잘린다.
- 말풍선 글자가 작게 나옴: 대사를 줄이거나 `fontScale`을 올린다. 말풍선 폭 `w`를 키우면 줄 수가 줄어든다.
- 한글이 네모로 나옴: 시스템에 한글 글꼴이 없다. `fontFile`로 글꼴 파일을 준다.
- `layout.html`은 합성에 쓴 HTML이다. 열어 보면 위치 조정 상태를 브라우저에서 확인할 수 있다.

## 9. Claude가 직접 그리는 컷 그림 (art 경로)

외부 이미지 생성 도구가 없거나 계정을 쓰기 어려울 때, 같은 캐릭터를 모든 컷에 일관되게 쓰고 싶을 때, 수정이 잦을 때 이 경로를 쓴다. Claude가 컷마다 SVG를 쓰고, 스크립트가 Chromium으로 PNG를 렌더한다. 도형과 그라데이션으로 만든 일러스트이며 사진이나 AI 생성 그림의 질감과는 다르다.

맞는 소재와 맞지 않는 소재는 다음과 같다.

| 잘 맞는다 | 맞지 않는다(외부 도구나 실제 사진으로) |
|---|---|
| 둥근 마스코트, 의인화한 사물(냄비·컵·빵), 음식, 주방·카페 같은 배경, 도형으로 단순화한 인물 | 사실적인 얼굴·몸·손, 복잡한 동작, 제품의 실제 사진 질감, 실제 간판과 로고 |

### 흐름

1. `art-size`로 컷별 캔버스 크기를 본다. 4:5 4컷은 980×1070이다. 이 크기로 `viewBox`를 쓰면 합성할 때 비율이 맞는다.
2. `art-init --link`로 컷별 뼈대 SVG와 spec의 `art` 경로를 만든다. 뼈대 주석에 컷의 장면·구도·캐릭터 앵커·말풍선 자리가 들어 있다.
3. 캐릭터를 한 번 정한다. 몸 path, 색, 얼굴 조합, 볼터치 위치를 정해서 모든 컷에 같은 조각을 복사해 쓴다(크기와 위치만 바꾼다). 이것이 art 경로의 캐릭터 앵커다. 캐릭터 이름과 조각은 첫 컷을 그린 뒤 spec의 `characters[].anchor`에도 적어 둔다.
4. 컷마다 층 순서대로 그린다: 배경 → 바닥·큰 사물 → 캐릭터 → 앞 사물 → 김·빛. 그림자는 몸 아래의 어두운 타원에 `filter="url(#wt-b14)"`, 빛 번짐은 밝은 원에 `wt-b28`을 쓴다. 면마다 밝은 하이라이트 타원(투명도 0.2~0.5)을 하나씩 얹으면 입체감이 생긴다.
5. 공용 정의는 SVG에 자동으로 들어간다. 그라데이션 `wt-g-main`(캐릭터 주색), `wt-g-accent`, `wt-g-paper`(밝은 사물), `wt-g-bg`(배경 위에서 아래), 번짐 `wt-b6`·`wt-b14`·`wt-b28`, 얼굴 `wt-face-sleepy`·`happy`·`wide`·`smile`(두 눈 사이가 원점), 볼터치 `wt-blush`. 얼굴은 `<use href="#wt-face-happy" transform="translate(x y)"/>`로 올리고, `palette.main`은 얼굴 선(진한 갈색)보다 밝은 색으로 둔다.
6. `art --guides`로 렌더하고 PNG를 눈으로 본다. 확인할 것: 말풍선 자리(빨간 점선)가 비어 있는가, 인물이 컷마다 같은가, 요소가 잘리거나 떠 있지 않은가(그림자와 바닥이 맞는가), 색이 3~5개 안에서 통일되는가. 고칠 곳이 있으면 해당 컷만 수정해 두 번까지 다시 그린다. 두 번 고쳐도 어색하면 그 컷은 외부 도구용 프롬프트(`prompts`)로 돌린다.
7. `compose`에서 art 컷은 자동으로 렌더되어 말풍선이 올라간다. 렌더된 PNG는 출력 폴더의 `art/`에 남는다.

### 규칙

- SVG 안에 `<text>`를 넣지 않는다. 시계 숫자 같은 소품 글자가 꼭 필요하면 `<svg>` 태그에 `data-allow-text`를 붙이되, 매장 이름·로고·간판 문구는 그리지 않고 `overlays`로 올린다.
- 외부 자원(이미지 링크, 웹폰트)을 쓰지 않는다. 한 파일 안에서 끝낸다.
- 실존 인물이나 기존 만화 캐릭터를 닮게 그리지 않는다. 캐릭터는 이 작품을 위한 새 형태로 설계한다.
- 한 컷의 `image`와 `art`를 함께 적으면 `image`가 쓰인다. 컷마다 경로를 섞어도 된다(예: 인물 컷은 외부 도구, 사물 컷은 art).
- `artStyle: "flat"`은 그라데이션과 번짐 없이 평면 색으로 렌더한다. 같은 SVG를 두 질감으로 비교해 보고 정하면 된다.
