# NeoDesign 선택형 선화 애니메이션

SVG 선과 TypeScript 동작으로 장면을 만든다. Claude API나 이미지 생성 서비스가 필요한 기능이 아니다.
원본 라이브러리는 `vendor/`에 고정했다. 원본 커밋과 해시는 `vendor/provenance.json`, MIT 고지는 `vendor/LICENSE`에 있다.

## 경로와 검토 범위

- 이 기능을 선택한 선화 장면에만 적용한다. 부모 스킬의 일반 영상 기본 엔진은 유지한다.
- SRT·설명 문장을 차례로 쓰는 영상은 `../whiteboard-video/SKILL.md`로 보낸다.
- 신규 디자인의 세 방향을 실제 초안으로 보여줄 때 인물 또는 장면 한 구석을 함께 그려 비교한다. 이미 승인한 방향·인물이 있으면 다시 선택을 요구하지 않는다. 유지보수·도구 테스트는 새 디자인 승인을 받는 작업이 아니다.
- 요청받은 형식을 구분한다. 웹 결과는 클릭·드래그 가능한 SVG이고 MP4는 고정 해상도·상호작용 없는 영상이다. 단일 HTML이 필요하면 빌드 자산을 실제로 묶고 네트워크 없이 다시 열어 확인한다. Vite 빌드 폴더를 단일 HTML이라고 부르지 않는다.

## 작업 순서

1. `vendor/references/style.md`와 가까운 `vendor/examples/walker/` 또는 `village/`를 읽는다. 종이·펜 굵기·인물 비례·포인트 색을 정한다.
2. 이 스킬 폴더에서 `node scripts/line-art.mjs doctor`로 환경을 확인한다. `node scripts/line-art.mjs init <새 프로젝트 폴더>`는 예제·라이브러리·MIT 고지를 복사하며 기존 폴더에는 쓰지 않는다.
3. 새 프로젝트에서 `npm ci --ignore-scripts`, `npm run typecheck`, `npm run build`를 실행한다. 개발 서버는 `npm run dev -- --host 127.0.0.1`. 설치 실패를 실행 성공으로 보고하지 않는다.
4. 인물 한 개를 먼저 그린다. `vendor/references/motion.md`에 따라 `gait()`로 걷고, 옷·소품은 뼈대와 spring/pendulum에 연결한다. 발이 디딘 동안 미끄러지지 않도록 이동 속도와 보폭을 맞춘다.
5. 승인한 기준으로 장면을 확장한다. `vendor/references/scenes.md`의 레이어·빛·낮밤 팔레트·상호작용을 사용한다. 키보드 조작·명확한 접근 가능한 이름·모션 줄이기 대안도 확인한다. 실제 사용자가 요청하지 않은 소품을 덧붙이지 않는다.
6. `vendor/references/verify.md`와 아래 검수 기준을 적용한다. 자동 실행 통과와 사람의 동작 판독을 분리해 기록한다.

## 검수와 시간 계약

- 독립 장면의 `?debug`는 `window.__step(seconds)`로 시간을 **앞으로 누적**한다. 절대 시각 seek가 아니다. 특정 시각을 재검사할 때 새 페이지에서 시작한다.
- 기본 스텝은 1/60초다. 현재 실행 도우미의 캡처 fps는 15·30·60으로 제한한다. 24fps처럼 60을 나누지 못하는 간격은 시간이 왜곡될 수 있으므로 거부하고, 필요하면 60fps 원본에서 별도 변환한다.
- 걷기 한 주기의 여러 포즈, 시작·중간·끝, 클릭 반응 뒤 복귀, 낮·해질녘·밤을 캡처한다. 발·손·소품을 확대해 겹침·접지·루프 끊김을 본다.
- reduced-motion 환경에서 정지 대안과 키보드 조작을 확인한다. 실제 브라우저 성능을 측정하지 않았다면 60fps 동작을 보장하지 않는다.
- 브라우저 오류·누락 자산·빈 프레임을 확인하고 MP4를 만들었다면 FFprobe로 해상도·프레임 수·길이를 대조한다. 테스트 예제 성공을 새로 제작한 장면의 검수 완료로 확장하지 않는다.

## 참고 영상과 출력

참고 영상 요청에만 `vendor/references/matching.md`를 읽는다. 가능한 로컬 MP4를 확보해 주기와 포즈를 측정한다. URL은 로그인·삭제·다운로드 제한으로 실패할 수 있다. 링크 접근을 영상 분석 성공으로 보고하지 않는다. 타인의 캐릭터는 새 디자인으로 바꾼다.

MP4가 필요하면 [실행·캡처 안내](references/runtime.md)를 읽는다. Windows 크롬 탐색, 출력 보호, 인코딩은 `scripts/line-art.mjs`가 처리한다.
처음 2초 정도를 시험한 뒤 요청한 길이를 렌더한다. 배포물에 복사한 라이브러리가 있으면 MIT 고지를 포함한다.
HyperFrames/OpenFilm과 합성할 때는 먼저 이 장면을 영상으로 출력해 미디어 클립으로 넣는다. 원본의 누적 스텝과 다른 엔진의 절대 시각 계약을 같은 파일에 억지로 섞지 않는다.

## 요청 예시

```text
네오디자인스튜디오의 선화 기능으로 새벽 빵집을 만들어줘.
쟁반을 든 제빵사, 오븐의 김, 창가 고양이.
먼저 인물과 선 느낌을 비교할 세 방향을 보여줘.
선정 뒤 상호작용 웹 장면과 30초 1080p MP4를 만들어줘.
```

납품할 때 웹 소스/빌드, 영상의 실제 사양, 확대 프레임 검수 결과, 라이선스, 남은 한계를 구분한다.
