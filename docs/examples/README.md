## 공통 사용법

각 문서는 목표와 대상, 제작 절차, 재현용 한국어 요청, 검수 기준을 포함합니다. 실제 데이터를 사용하는 사례는 원본 출처와 범위를 먼저 확인하고, 생성된 시각 자료는 실제 작동 결과인지 콘셉트 예시인지 구분해서 기록합니다.

## 추가 사례를 만들 때

새 사례는 [프로젝트 실행 규칙](../../SKILL.md)의 구조를 따릅니다. 수치·외부 사실·사용자 소유 자료는 문서 끝에 원본 링크를 남기고, README에는 독자가 다음 행동을 취할 수 있는 짧은 설명과 링크만 배치합니다.
