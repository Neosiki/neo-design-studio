# 데이터저널리즘 사례: 한반도 지진 기록을 읽을 수 있는 이야기로 바꾸기

> **한 줄 요약**: 공개 지진 기록을 정리하고 지도·카드·세로형 영상으로 연결해, 단순한 숫자 목록을 학습 가능한 데이터 이야기로 바꾸는 사례입니다.

이 사례는 사용자 소유 프로젝트인 [korean-earthquake-data-journalism](https://github.com/Neosiki/korean-earthquake-data-journalism)을 바탕으로 작성했습니다. 원본 프로젝트에는 지진 데이터 시각화, 한국어 설명, 카드형 이미지와 영상 자료가 함께 들어 있으므로, **자료 수집 → 정제 → 시각화 → 설명 → 검수**의 전체 흐름을 연습하기에 적합합니다.[^1]

## 목표와 대상

대상은 지역·기간별 지진 기록을 처음 읽는 학습자와, 공공 데이터를 시민이 이해할 수 있는 시각적 이야기로 바꾸려는 제작자입니다. 핵심 질문은 “어떤 기간과 지역의 기록을 어떤 단위와 시각 언어로 보여 주어야 과장 없이 이해되는가?”입니다.

| 항목 | 내용 |
| --- | --- |
| 입력 | 원본 지진 기록, 지역명, 발생 시각, 규모·깊이 등 제공 필드 |
| 출력 | 정제된 표, 지도 또는 분포 그래프, 한국어 카드, 세로형 설명 영상 |
| 사례 포인트 | 데이터 계약과 출처를 먼저 고정한 뒤 시각 언어를 선택한다. |
| 주의 | 기록의 개수는 관측·수집 범위에 따라 달라지므로 전체 지진의 절대적 빈도로 해석하지 않는다. |

## 1. 자료 계약부터 고정하기

먼저 원본 저장소의 데이터 파일과 설명을 확인하고, 다음 항목을 `source-note.md`에 기록합니다.

| 확인 항목 | 기록할 내용 |
| --- | --- |
| 원천 | 파일을 제공한 프로젝트와 원본 URL |
| 기간 | 데이터의 시작일과 마지막 갱신일 |
| 단위 | 규모, 깊이, 거리, 시간대의 단위와 표기 규칙 |
| 지역 | 시도·시군구·좌표 중 실제로 제공되는 위치 수준 |
| 결측·중복 | 비어 있는 값, 중복 행, 좌표 오류를 처리한 방법 |
| 범위 | 데이터가 말할 수 있는 것과 말할 수 없는 것 |

데이터를 내려받기 전에 파일의 열 이름과 값의 범위를 확인합니다. 동일한 단어가 장소명·관측소명·행정구역을 가리키지 않는지 구분하고, 숫자를 문자열로 읽어버리는 변환 오류를 먼저 막습니다.

## 2. 정제와 질문 만들기

처음부터 장식적인 지도를 만들지 말고, 한 가지 질문을 고릅니다. 예를 들어 “어느 지역에 기록이 집중되는가?” 또는 “시간에 따라 기록 분포가 어떻게 달라지는가?”처럼 질문의 주어와 단위를 명확히 씁니다.

정제 단계에서는 다음 순서로 확인합니다.

1. 필수 열과 자료형을 확인합니다.
2. 날짜·시간대를 하나의 규칙으로 정규화합니다.
3. 규모·깊이의 결측치를 임의의 0으로 대체하지 않습니다.
4. 좌표가 비어 있거나 지역명과 맞지 않는 행을 별도로 표시합니다.
5. 동일 사건을 중복 집계하지 않도록 식별 기준을 기록합니다.
6. 정제 전후 행 수와 제외된 행의 이유를 남깁니다.

## 3. 시각화와 한국어 설명 연결하기

지도는 위치를 설명할 때만 사용하고, 기간별 비교가 핵심이면 막대·선·분포 차트를 우선 검토합니다. 한 화면에는 질문 하나와 단위 하나만 둡니다. 색상 범례에는 색의 의미와 단위를 함께 쓰고, 색이 진할수록 위험하다는 식의 해석을 데이터가 직접 뒷받침하지 않는다면 사용하지 않습니다.

한국어 카드와 세로형 영상은 다음 구조를 사용합니다.

| 장면 | 전달 내용 | 검수 질문 |
| --- | --- | --- |
| 시작 | 무엇을, 어느 기간에 보았는가 | 출처와 기간이 보이는가? |
| 본문 | 지역·기간별 패턴은 무엇인가 | 단위와 범례가 빠지지 않았는가? |
| 한계 | 누락·관측 범위·집계 기준 | 데이터가 말하지 않는 것을 과장하지 않는가? |
| 마무리 | 원본·상세 자료로 이동 | 독자가 재확인할 링크가 있는가? |

원본 프로젝트의 대표 시각화 카드는 [media/01_overview.png](https://github.com/Neosiki/korean-earthquake-data-journalism/blob/main/media/01_overview.png)에서 확인할 수 있습니다.[^2]

## 재현용 한국어 요청 예시

```text
한반도 지진 기록을 시민이 이해할 수 있는 데이터저널리즘 사례로 정리해줘.
원본 파일의 열 이름·기간·단위를 먼저 표로 확인하고, 결측치와 중복 처리 기준을 명시해줘.
그 다음 질문 하나를 선택해 지도 또는 비교 차트로 제안하고,
한국어 설명 카드 3장과 60초 세로형 영상의 장면별 내레이션을 작성해줘.
각 결과물에는 출처·수집 기간·단위·해석의 한계를 넣고, 확인되지 않은 인과관계는 주장하지 마.
```

## 완성 전 검수 체크리스트

| 검수 영역 | 통과 기준 |
| --- | --- |
| 출처 | 원본 저장소와 사용한 파일이 연결되어 있다. |
| 범위 | 기간·지역·갱신일이 표시되어 있다. |
| 숫자 | 단위·반올림·결측 처리 방식이 설명되어 있다. |
| 시각화 | 범례·축·색상 의미가 독립적으로 이해된다. |
| 서술 | 상관관계를 원인으로 과장하지 않는다. |
| 재현성 | 독자가 원본 자료와 요청 예시를 따라갈 수 있다. |
