# 3D 학습 앱 사례: 관찰하고 조작하며 확인하는 학습 흐름

> **한 줄 요약**: 3D 모델을 단순히 보여 주는 화면을 학습자가 직접 관찰·조작·확인하는 단계형 학습 경험으로 전환하는 사례입니다.

이 문서는 `assets/readme/korean-3d-learning-app.png`의 한국어 UI 예시 시각 자료와 함께 사용하는 **제품 설계 사례**입니다. 이미지는 실제로 배포된 앱의 작동 증거가 아니라, 화면 구성과 학습 흐름을 설명하기 위한 콘셉트 이미지입니다.

## 목표와 대상

대상은 3D 모델을 처음 다루는 학습자와, 시각 자료를 수업 단계로 바꾸려는 제작자입니다. 학습자는 모델을 회전·확대·축소하고, 특정 부위를 선택하고, 단계별 질문에 답한 뒤 자신의 관찰 결과를 확인합니다.

| 항목 | 설계 기준 |
| --- | --- |
| 학습 목표 | 모델의 구조를 관찰하고, 이름·위치·관계를 설명한다. |
| 상호작용 | 회전, 확대·축소, 부위 선택, 카메라 초기화 |
| 학습 단계 | 관찰 → 선택 → 질문 → 피드백 → 다시 보기 |
| 출력 | 학습 화면, 단계별 피드백, 복습용 요약 카드 |
| 품질 기준 | 조작 가능성, 텍스트 가독성, 단계 전환의 명확성, 키보드·대체 설명 |

## 화면과 상태 설계

3D 화면을 한 장의 예쁜 이미지로 끝내지 않고, 사용자가 무엇을 해야 하는지 상태별로 정의합니다.

| 상태 | 화면에 보여 줄 것 | 사용자의 행동 | 통과 조건 |
| --- | --- | --- | --- |
| 시작 | 모델 전체, 학습 목표, 시작 버튼 | 목표 읽기·시작 | 첫 행동이 분명하다. |
| 관찰 | 모델, 회전·확대 안내, 초기화 | 모델 살펴보기 | 어느 방향에서도 모델이 잘리지 않는다. |
| 선택 | 선택 가능한 부위의 강조 | 부위 선택 | 선택 상태와 해제가 구별된다. |
| 질문 | 한국어 질문과 선택지·입력 | 관찰 결과 답하기 | 질문이 현재 선택 부위와 연결된다. |
| 피드백 | 정답·오답 이유, 다시 관찰하기 | 설명 읽고 재시도 | 실패가 다음 행동을 안내한다. |
| 복습 | 핵심 구조와 내가 선택한 답 | 요약 확인 | 학습 결과를 다시 볼 수 있다. |

## 제작 절차

### 1. 학습 단위를 하나로 제한하기

처음부터 복잡한 모델 전체를 설명하지 않습니다. 한 화면에서 관찰할 구조와 학습 질문을 하나로 정하고, 나머지 정보는 다음 단계로 보냅니다.

### 2. 조작 계약을 먼저 작성하기

회전 방향, 확대·축소 방식, 초기화 위치, 선택 가능 영역을 한국어로 먼저 작성합니다. 마우스만 가정하지 말고 키보드 포커스와 터치 입력에서 같은 목표에 도달할 수 있는지 확인합니다.

### 3. 피드백을 관찰 행동과 연결하기

“틀렸습니다”로 끝내지 않고, 다시 확인할 부위·관찰 방향·관련 개념을 안내합니다. 정답 설명은 화면의 현재 상태와 연결되어야 하며, 학습자의 선택을 잃지 않아야 합니다.

### 4. 단계 전환을 검수하기

시작·관찰·질문·피드백·복습 상태를 순서대로 통과하고, 새로고침·뒤로 가기·모델 초기화 뒤에도 학습자가 현재 위치를 알 수 있는지 확인합니다.

## 재현용 한국어 요청 예시

```text
중학생이 5분 안에 하나의 3D 구조를 관찰하고 설명할 수 있는 학습 앱 화면을 설계해줘.
화면은 시작·관찰·부위 선택·질문·피드백·복습 상태로 나누고,
각 상태마다 모델 조작법, 한국어 안내, 다음 행동, 실패 시 재시도 방법을 작성해줘.
마우스뿐 아니라 키보드와 터치 입력을 고려하고, 선택 상태와 모델 초기화 버튼을 명확히 보여줘.
결과물은 실제 작동을 주장하지 않는 UI 콘셉트 이미지와 구현 체크리스트로 구분해줘.
```

## 접근성과 시각 품질 검수

| 영역 | 검수 기준 |
| --- | --- |
| 텍스트 | 작은 화면에서도 본문·버튼·상태 안내가 읽힌다. |
| 색상 | 색만으로 선택·정답·오답을 구분하지 않는다. |
| 키보드 | 포커스 순서와 현재 선택 상태를 알 수 있다. |
| 터치 | 모델 조작과 버튼 입력이 충돌하지 않는다. |
| 3D 조작 | 회전·확대·초기화 방법이 첫 화면에 안내된다. |
| 피드백 | 오답 이유와 다시 관찰할 행동을 함께 제공한다. |
| 이미지 설명 | 콘셉트 이미지의 목적과 실제 작동 여부를 명시한다. |

## 확장 아이디어

첫 번째 버전은 한 구조와 한 질문으로 시작하고, 이후 학습자별 난이도, 단계별 힌트, 복습 카드, 교사용 관찰 기록으로 확장합니다. 기능을 추가할 때는 장식보다 학습 목표와 검수 가능성을 우선합니다.
